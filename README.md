# SISGED-FRONTEND

MVP estático do SISGED preparado para GitHub Pages e Cloudflare Pages.

## Publicação
- Arquivo de entrada: `index.html`
- Build: nenhum
- Diretório de saída: raiz do projeto
- Tecnologia: HTML, CSS e JavaScript

## Limitações
Esta versão não executa PHP, não acessa MySQL/MariaDB e não implementa autenticação real. Cadastros, pesquisas e login são simulados no navegador para demonstração do front-end.

## Segurança
Não foram incluídas senhas, tokens, chaves privadas ou credenciais de banco.

## Teste local
Abra `index.html` no navegador ou use um servidor HTTP local. Para testar o fluxo, preencha qualquer login e senha e clique em ENTRAR.
